# Học viện An toàn số
Học viện An toàn số là website giáo dục kỹ năng an toàn trên không gian mạng dành cho học sinh THCS, cung cấp kiến thức về bắt cóc online, biểu hiện, hướng xử lý khi gặp nguy hiểm và các quy định pháp luật liên quan. Đồng thời, website các cấp độ thực hành với tình huống giả định, giúp học sinh có cách ứng phó an toàn và xử lý các tình huống.
